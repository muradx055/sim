# Помощник по 1С

Программа для Windows. Запускаете её, наводите мышь на кнопку или пункт меню 1С — рядом появляется пояснение, что это и зачем. Работает в окне запуска, в Конфигураторе и в режиме «1С:Предприятие».

## Как пользоваться

1. Распакуйте архив в любую папку (например, на рабочий стол). Не запускайте exe прямо из архива.
2. Запустите **«Помощник по 1С.exe»**. При первом запуске Windows может показать синее окно «Windows защитила ваш компьютер» — программа новая и не имеет платной подписи. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Выберите, где показывать подсказки:
   - **Только в окнах 1С** — подсказки появляются, только если мышь над окном 1С (по умолчанию);
   - **В выделенной области** — нажмите «Выделить область…» и протяните прямоугольник на экране;
   - **На всём экране** — в любых программах (подсказки пишутся только для 1С).
4. Нажмите **«Запустить»**, откройте 1С и наведите мышь на кнопку. Через полсекунды появится подсказка.
5. **Ctrl+Alt+H** — пауза и продолжение.

## Как пополнять подсказки

Все подсказки лежат в файле `hints_1c.json` рядом с программой (кнопка «Открыть словарь подсказок»). Его можно править в Блокноте:

```json
{ "match": ["Записать и закрыть"], "ctx": ["ent"], "title": "Записать и закрыть", "text": "Сохранить данные и закрыть форму." }
```

- `match` — как кнопка называется на экране (регистр не важен, можно несколько вариантов);
- `ctx` — где показывать: `launcher` (окно запуска), `cfg` (Конфигуратор), `ent` (1С:Предприятие). Без `ctx` — везде;
- `title`, `text` — заголовок и пояснение.

Чтобы быстро узнать, каких подсказок не хватает, включите **«Режим словаря»**: программа будет записывать названия кнопок без подсказки в файл `unknown.log`. Добавьте для них записи в словарь и перезапустите помощника.

## Если подсказки не появляются

- Проверьте, что выбран режим «Только в окнах 1С» или область действительно накрывает окно 1С.
- 1С рисует часть элементов сама, и Windows не всегда знает их названия. Для таких случаев в программе есть чтение надписей с экрана (OCR). Ему нужен русский язык распознавания: Параметры Windows → Время и язык → Язык и регион → Русский → Языковые параметры → «Оптическое распознавание текста».
- Кнопки, у которых есть только значок без надписи, программа не читает.
- Включите «Режим словаря» и посмотрите `unknown.log`: так видно, какие названия программа получает от 1С.

## Для разработчика

- `helper.py` — окно настройки, всплывающая подсказка, опрос элемента под курсором (UI Automation + OCR).
- `hintlib.py` — сопоставление названий элементов со словарём (не зависит от Windows, покрыт тестами).
- Запуск тестов: `pip install pytest && python -m pytest tests`.
- Проверка собранной программы: `Helper1C.exe --selftest` (результат в `selftest.log`).
- Сборка exe выполняется автоматически в GitHub Actions (`.github/workflows/build-1c-helper.yml`) при каждом изменении папки `1c-helper`; готовый архив попадает в раздел Releases.
